# Glossary

- **Hot wallet:** online wallet that signs automatically under policy; sized for short-term withdrawals.
- **Warm wallet:** buffer tier with semi-automated or human-approved signing used to refill the hot wallet.
- **Cold storage:** offline or air-gapped keys used through scheduled, multi-party ceremonies.
- **Risk engine:** rule and scoring system that approves, holds or rejects withdrawals before signing.
- **Address whitelist:** pre-registered destinations, usually with a cooling-off delay before use.
- **Signer-side policy:** checks run by the signer itself that the transaction matches an approved request.
- **HSM:** hardware security module; tamper-resistant device that generates keys and signs without exporting them.
- **MPC / threshold signing:** several parties holding key shares jointly produce one signature without reconstructing the key.
- **PSBT:** Partially Signed Bitcoin Transaction (BIP 174), a format for passing transactions between signers.
- **Three-way reconciliation:** comparing internal ledger, wallet system and chain balances.
- **Delegatecall:** EVM call that runs another contract's code in the caller's storage context; used to swap a proxy's implementation.
- **Proof of reserves:** public evidence that an exchange controls assets at least equal to committed user liabilities.
